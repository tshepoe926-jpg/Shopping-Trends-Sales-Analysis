# Shopping-Trends-Sales-Analysis
For this projects I was able to gain insights on Sales performance, Product trends, Seasonal trends, Market effectiveness and Subscribers vs No Subscribers effect on sales.  

First step was the introduction to the project.

Second step I created a mind map brainstorming ideas on what information to exctract.

Third step I created a project plan on the duration and time spent using specific tools. 

Forth step was to extract sales insights from the data set. 

Fifth step was to extract customer insights. 

Sixth step was to extract the product insights. 

The seventh step was to give key insights and recommendations on all information I was able to extract from this data set.

Tools that were used on this project was Excel to clean data and create visuals. Power BI to extract Subscriber vs Non Subscriber. Canva to create a presentation.
